# 拼音小星球 · Pinyin Planet

面向 4–7 岁儿童的汉语拼音启蒙 Web 应用（WebView 壳 + H5 内核）。
听 → 读 → 写三合一：单字范读、跟读录音对比、四线三格描红打分；无广告、无会员、无内购、离线可用。

> 本仓库开源，欢迎共同完善发音与教学内容。**发音部分目前仍有已知问题（见下方「待修复」），特别欢迎熟悉中文语音合成 / 拼音教学的同学贡献。**

## 在线预览

H5 为纯静态页面，直接用浏览器打开 `www/index.html` 即可预览（建议 Chrome / Edge，允许媒体自动播放）。
手机上可通过任意 WebView 壳加载本地 `www/` 目录。

## 课程内容

- **23 个声母**、**24 个韵母**、**16 个整体认读音节**，共 63 课。
- 每个课时含：字母音、例词、儿歌口诀、四个声调范读、跟读对比、四线三格描红。
- 声母页另有「拼一拼，读四声」（声母 + 韵母拼合，如 bā 八 / bá 拔 / bǎ 把 / bà 爸）。

## 音频命名约定（`www/audio/`）

| 前缀 | 含义 |
|------|------|
| `l-<字母>.mp3` | 声母呼读音（如 l-b.mp3 = 玻） |
| `w-<字母>.mp3` | 例词汉字发音 |
| `k-<字母>.mp3` | 儿歌口诀整句 |
| `x-<字母>.mp3` | 书写提示朗读 |
| `tp-<韵母>-<1..4>.mp3` | 韵母四声范读（96 条） |
| `sy-*` | 整体认读音节发音 |
| `sc-*` | 声母拼四声范读 |
| `t-*` / 其他 | 其余例词与补充发音 |

## 发音引擎（`js/audio.js`）

按优先级三层回退：

1. **内置离线 mp3**：`audio-map.js` 把文本映射到 `www/audio/*.mp3`，离线打包最稳定；
2. **安卓原生 TTS**：WebView 容器注入 `window.PyNative`；
3. **浏览器 Web Speech API**：电脑浏览器兜底。

## 音频生成方式

现有范读音频由 [edge-tts](https://github.com/rany2/edge-tts) 合成：

- 音色：`zh-CN-XiaoyiNeural`（晓伊童声）
- 语速：`--rate=-20%`（口诀约 -15%）
- 后处理：ffmpeg 响度归一化（loudnorm）、补静音到统一时长。

批量合成示例见 `scripts/batch_edge.sh`；韵母四声清单见 `scripts/jobs_single.tsv`。

## ⚠️ 待修复的已知发音问题（欢迎认领）

这是开源的主要原因，当前自动合成的普通话范读在以下方面不达标，建议优先处理：

1. **语气助词四声区分不明显**
   `啊 / 哦 / 噢 / 诶 / 嗯 / 嗡` 这类语气词在没有语境时，edge-tts 常一律读成轻声，导致二/三/四声音频接近甚至相同。
   现在用标点语境强制（`啊？` `啊！` `啊，`），但效果仍不稳定。建议改用专业录制的单音节范读，或支持拼音声调标注的语音库。

2. **多音字靠词语裁切，可能残留尾音**
   - 恶(ě) 取自「恶心」、为(wèi) 取自「因为」、晕(yūn) 取自「晕倒」等；
   - 用 ffmpeg 裁到第一个音节，裁切边界不准时会残留后一字尾音。建议更换为读音唯一的单字，或重新录制。

3. **无独立汉字的韵母用了语气词近似**
   以下韵母在普通话里没有常用独立汉字，当前用近似语气词顶替，**不是教材标准范读**：
   - ei 二/三/四声；en 二/三/四声；eng 全部四声；ong 全部四声；
   - ou 二/四声；üe 二/三声；er 一声；an 二声；ang 三/四声。
   建议参照小学语文教材，用标准范读音（纯韵母 + 调值）重新录制。

4. **极短音节响度可能偏轻**：loudnorm 对单音节短音频的响度修正不稳，部分片段听感偏小，需逐条人工核对音量。

### 推荐改进方向

- 用真人 / 专业 TTS 逐条录制 96 条 `tp-<韵母>-<1..4>.mp3`，保证四声调值（阴平 55、阳平 35、上声 214、去声 51）清晰可辨；
- 建立「拼音 → 规范汉字/词语」对照表，避免多音字被读成最常见读音；
- 合成后自动校验：同韵母四条音频 MD5 互不相同、时长与响度在阈值内、无静音空壳。

## 打包成 Android APK

H5 是纯静态资源，Android 侧为一个加载本地 `www/` 的 WebView 壳：

1. 新建 WebView 工程，把 `www/` 放进 `assets/www/`；
2. `WebView` 启用 JS、离线读 `file:///android_asset/www/index.html`；
3. 音频相对路径 `audio/xxx.mp3` 由 `js/audio.js` 内 `playFile` 拼接 `audio/` 前缀，注意不要再多加一层目录；
4. 打包后用 `zipalign` 对齐、`apksigner` 签名即可。

> 仓库不含签名密钥与构建好的 APK（见 `.gitignore`），请勿提交 `*.keystore`、`*.idsig`、`*.apk`。

## 开发调试

- 本地静态服务：在 `www/` 目录执行 `python3 -m http.server 8899`，浏览器访问 `http://127.0.0.1:8899/`。
- 路由为 hash：`#/lesson/sm-b`、`#/lesson/ym-a`、`#/lesson/ym-%C3%BC`（ü 需 URL 编码）、`#/tone`。
- 课程数据集中在 `js/data.js`，改例字、口诀、四声表优先改这里。
